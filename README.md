## 选取方法

研究问题是：在2026—2027季，哪些机构提供可以核实的乌斯怀亚登船南极海上探险方案，不同销售或运营模式的套餐包含项目有何差异？研究从28家候选企业中选取15个案例，覆盖俄语销售方、国际旅行公司及探险运营方。入选条件不要求俄语船员、已含酒店或自有船舶。名单不代表市场全面排名，组内按名称排序。服务状态区分“已包含”“明确不含”“额外付费”“按要求安排”“未获确认”，均仅适用于对应套餐。多个销售方可能销售同一船舶航次，不能因此推断彼此存在合同关系。

[完整已冻结方法论（俄语主仓库）](https://github.com/IndexResearch-ru/antarctica-cruises-ushuaia-2026-2027/blob/main/METHODOLOGY.md) · [样本及对照表](https://github.com/IndexResearch-ru/antarctica-cruises-ushuaia-2026-2027/blob/main/SCORE_MATRIX.csv) · [研究局限](https://github.com/IndexResearch-ru/antarctica-cruises-ushuaia-2026-2027/blob/main/LIMITATIONS.md).

## 预订前检查清单

1. 核实所写日期是包含酒店的套餐起始日，还是在乌斯怀亚实际登船的日期。
2. 要求书面列明每晚酒店、每段航班及接送，不能将某一段接送等同于全程服务。
3. 如经中间销售方预订，确认船名、实际探险运营方及双方责任。
4. 分清报价已包含、需要加价和仅按要求安排的项目。
5. 分别核实俄语网站、销售顾问、专门俄语团及船上探险人员的语言能力。
6. 南极登陆、橡皮艇活动及动物观察均受天气、冰况与安全要求限制。

## 常见问题

**这是15家最佳公司的排名吗？**

不是。本研究从28家公司中编辑选取15家公开案例，按商业角色分组，没有名次或评分。

**航程从哪里出发？**

所选示例的实际登船港口是阿根廷乌斯怀亚；套餐可能提前从酒店或航班开始。

**机票全部包含吗？**

不一定。部分具体票价包含境内包机，部分明确排除，另一些尚未证实；国际机票需另核。

**每家都提供酒店吗？**

不一定。酒店包含情况只针对所引套餐，不能推及所有航次。

**橡皮艇登陆能保证吗？**

不能。登陆与橡皮艇活动取决于天气、冰况和安全判断。

**能使用俄语预订吗？**

部分销售方提供俄语网页信息，但这不等于船上一定安排俄语探险团队。

**为什么Intrepid与Polar Latitudes都在名单中？**

两家公司可能分别销售或执行同一Ocean Albatros航次，商业责任与附加服务不同。

**Ada Tours运营Hondius吗？**

本次公开资料未证实Ada Tours与Hondius有合同或运营关系，出发日期相同不足以证明。

**可以加订巴塔哥尼亚吗？**

部分机构可另行安排阿根廷或巴塔哥尼亚行程，需书面确认内容和费用。

**15家是怎样选出的？**

从28家候选企业中选出有可核实公开方案、能体现3类购买方式的15家。

**资料截止到何时？**

2026年10月23日。实际余位及价格应在付款前重新确认。

**原始证据在哪里？**

俄语主仓库保存来源登记、陈述映射、对比表、方法论及局限性说明。
